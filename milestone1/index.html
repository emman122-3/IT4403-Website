Project Homepage

Welcome to my IT 4403 Open Library project. This project demonstrates the use of JSON data, jQuery, JavaScript, HTML, and embedded CSS to create webpages that display information retrieved from Open Library data.

Milestone 1 focuses on working with two supplied JSON files. The first file contains information about a single book, while the second file contains multiple search results for the search phrase "modern web".

The project demonstrates how webpages can read structured JSON data, process arrays and nested objects, handle missing information, display book covers, and create links to Open Library records.

Individual Project Milestone

Milestone 1 demonstrates how Open Library JSON data can be processed and presented through webpages. The milestone contains a single-book webpage and a search-results webpage.

Single Book

This webpage reads the openlibrary-book.json file and displays information about the book Fantastic Mr. Fox.

The page displays the book title, author reference, publisher, publication date, page count, ISBNs, cover image, first sentence, and Open Library links.

View Single Book

Search Results

This webpage reads the openlibrary-search.json file and loops through the docs array to display the available search records.

Each book record displays information such as title, author, publication year, edition count, language, cover image, and Open Library link.

View Search Results

Project Files

The Milestone 1 project consists of the following files:

  • search.html - Search-results webpage
